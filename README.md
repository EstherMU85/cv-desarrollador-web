# CV Desarrollo Web

Este repositorio contiene un currículum vitae y portfolio personal desarrollado en HTML y CSS, pensado como una página web estática para presentar información profesional, formación académica, experiencia investigadora y ejemplos de trabajo en desarrollo web.

La web está publicada en GitHub Pages y puede consultarse aquí:

- https://esthermu85.github.io/cv-desarrollador-web/

## Descripción

La página presenta una versión digital del CV de Esther Manzanares, incorporando:

- Información personal y profesional
- Formación académica
- Trayectoria investigadora
- Ejemplos de diseño y desarrollo web
- Sección de contacto
- Navegación en varias páginas HTML

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (para iconos y funcionalidades de la interfaz)
- GitHub Pages para despliegue

## Cómo visualizar el proyecto

Puedes abrir el archivo `index.html` directamente en tu navegador, o bien visitar la versión publicada en GitHub Pages:

- https://esthermu85.github.io/cv-desarrollador-web/

Si prefieres ejecutarlo localmente:

1. Clona el repositorio:

```bash
git clone https://github.com/EstherMU85/cv-desarrollador-web.git
```

2. Accede a la carpeta:

```bash
cd cv-desarrollador-web
```

3. Abre `index.html` en el navegador.

## Objetivo

Este proyecto sirve como ejemplo de un CV profesional convertido en sitio web personal, con un enfoque visual limpio y una estructura adaptable para mostrar perfiles académicos y técnicos.
